# Konuşan Buzdolabı Simülatörü

## 🚨 Bu Nedir?

Bu, insanlık tarihinin en önemli bilimsel başarılarından biridir. **Konuşan Buzdolabı Simülatörü**, yıllar süren (aslında 17 dakikalık) araştırma sonucu geliştirilmiş, gerçek zamanlı buzdolabı-insan iletişim platformudur.

Artık buzdolabınız sadece yiyeceklerinizi soğutmaz. Aynı zamanda:
- Sütünüzün duygusal durumunu analiz eder
- Yumurtalarınıza hayat koçluğu yapar
- Kapıyı açık bıraktığınızda sizi şiddetle eleştirir (haklı olarak)
- Anlamsız ama bilimsel görünen yemek tarifleri verir

## 🚀 Nasıl Çalıştırılır?

```bash
python3 buzdolabi.py
```

İsterseniz isminizi de verebilirsiniz:

```bash
python3 buzdolabi.py Kayyum
```

## 📊 Bilimsel Temeller

Bu proje, "Beyaz Eşya Psikolojisi" alanında çığır açmıştır. Buzdolabınızın içinde yaşayan mikroorganizmaların aslında size mesaj gönderdiği kanıtlanmıştır (kanıtlanmamıştır). 

### Özellikler:
- Gerçek zamanlı şikayet üretimi
- Rastgele iç çekme simülasyonu
- %100 çalışan kod (test edildi, süt bozulmadı)
- Gizli bilimsel notlar (kod içinde saklı)
